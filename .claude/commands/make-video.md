Produce the video for story **$ARGUMENTS** with the studio engine in `studio/engine`. Work in real files and real renders; never claim quality you have not inspected.

## Rules
- **Art style is locked.** Characters are generated by `studio/engine/web/chargen.js` from structured specs. Do not invent new drawing styles, do not use AI-generated character art, and do not make characters more realistic.
- **No paid credits without explicit approval.** Narration/dialogue/music via Higgsfield (ElevenLabs) cost credits: quote the cost (narration ≈2.3 cr, 30 s music ≈4.5 cr) and ask first. Everything else in this pipeline is free.
- **Period accuracy.** Set `period` in story.json; `checkPeriod` must report no warnings, and set dressing must not contain anachronistic props.
- Fact-check claims in narration against the story's research notes from /develop-story before recording audio.

## Steps
1. **Setup (fresh session):** `bash studio/engine/tools/setup.sh` (three.js r160, Playwright, Poly Haven CC0 assets).
2. **Story folder** `studio/stories/<slug>/` (copy `studio/stories/roman-lime` as a template):
   - `story.json`: `period`, `set` (a module in `engine/web/sets/`), `duration`, `audio` {voice, voiceOffset, music, musicLUFS}, `dialogue` [{speaker, words, env, offset, script}], `ambience`.
   - **Cast bible** `cast`: one entry per principal character → `{spec, x, z, seed}`. Write each spec from the story's character descriptions (age, build, height, head shape, eyes, brows, nose, ears, wrinkles, hair, facial hair, outfit + clavi/sandals/apron/cape, headwear, prop, personality {energy, tempo, posture, exaggeration, walk}). Make principals recognisable by **silhouette** first (height, belly, shoulders, head shape, hair mass, headwear), then face. Principals must not resemble each other or the extras.
   - `extras`: `{seed, role: civilian|worker|soldier, x, z, beats, path}`. These are generated by `periodExtra` (period wardrobe, half-res cards).
   - `performances[id]`: `beats` [{t, act, body, face, look, gesture, reachL/R, speak, faceTravel}] using the shared action library in `engine/web/acting.js` (idle, talk, notice, curious, lookAround, suspicious, disbelief, point, laugh, shock, recoil, stumble, fallSit, dazed, sheepish, fear, sad, confused, realize, angry, carry, effort) + `path` [{t, x, z}] for walking/running (the gait comes from distance travelled; the speed decides walk or run).
   - `shots`: [{name, a, b, keys:[{t, pos, look, fov, focus, ap}]}] covering the full duration; vary angles (wide / medium / insert / close).
   - `business.js` (optional): story-specific object interaction (props attached to hands via `cardToWorld(actor, handsMid(actor))`, particles, simple physics) + `cues()` for sound.
3. **Preview stills before the full render:** `node studio/engine/tools/render.mjs <slug> /tmp/stills "0,60,120,..."`. Inspect every shot: framing (nobody cut by the frame edge unless intended), faces never covered by props, props in hands, extras not upstaging or resembling principals, period dressing, lighting. Fix and repeat.
4. **Full pipeline:** `python3 studio/engine/tools/make_video.py <slug> --jobs 3`. Steps: validation → lip-sync data (align + loudness) → parallel render → cue sheet → SFX → mix (−14 LUFS) → 1080×1920 encode → QA sheet.
5. **Review:** open `build/qa_sheet.jpg`. Check lip-sync on close-ups (closed lips on m/b/p, rounded lips on o/w), acting and continuity between shots, and the `ffprobe` resolution line. Report remaining defects honestly. Keep deliverables under 50 MB for GitHub.
